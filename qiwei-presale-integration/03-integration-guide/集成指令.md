## 关键提醒(你自己要把关的)

1. **JSON 是中间层,不是终点**——每次让 CC 给 Prompt 加字段,务必同时改"JSON schema + 前端渲染 + 导出器"三处,缺一个就会出现"模型生成了但页面/文档看不到"。
2. **一期/二期边界是这套 skill 的命门**——这是它和普通方案生成器最大的区别。务必让 CC 在三个 Prompt 里都写死这条纪律,并在回归时交叉验证口径一致。
3. **日期取服务端当天**——别让模型自己编日期(它会编错或用训练截止日期)。在后端拼 Prompt 时把 `new Date()` 的当天日期作为变量传进去。
4. **分步验收,不要一次性全改**——按上面 1→2→3→4→5 顺序,每步让 CC 给 diff 和样例产物,你确认后再进下一步。
5. **skill 文件保持只读**——它是规格源。以后想调整产物风格,改 skill→让 CC 重新对齐 Prompt,保持单一事实来源。
