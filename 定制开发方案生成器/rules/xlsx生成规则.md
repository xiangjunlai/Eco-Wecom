# 智能表格 Xlsx 生成规则

## 文件基本信息

- 文件类型：`.xlsx`
- 默认字体：思源黑体 / 苹方
- 正文字号：11pt
- 表头：12pt 加粗
- 工作表数量：5-8 个

## 必备工作表（5 个核心 + 可选扩展）

### Sheet 1: 📊 数据看板（首页）
**这是默认打开的首页**，包含：

| 区块 | 内容 |
|---|---|
| KPI 大字 | 4-6 个核心指标（订单总数/打样中/在产/已发运/异常/本月营收） |
| 趋势图 | 近 7/30 天订单趋势、品类分布 |
| 待办列表 | Top 10 紧急事项（带超期红标） |
| 客户分布 | 按客户/区域/品类的占比饼图 |
| 状态分布 | 各状态订单的实时计数 |

每个 KPI 必须有"目标 vs 实际"双值。

### Sheet 2: 📦 订单总览
**主业务表**，字段（按行业调整）：

| 字段 | 类型 | 说明 | 权限 |
|---|---|---|---|
| 订单号 | 文本 | 唯一键 | 全员可见 |
| 客户 | 关联 | 客户档案 | 全员 |
| PO 号 | 文本 | 客户 PO | 跟单+财务 |
| 下单日期 | 日期 | | 全员 |
| 约定交期 | 日期 | | 全员 |
| 状态 | 枚举 | 待确认/打样/生产中/已发运/已完成/已取消 | 全员 |
| 总金额 | 数字 | ¥ | 跟单+财务+老板 |
| 已收款 | 数字 | ¥ | 财务+老板 |
| 欠款 | 公式 | 总金额 - 已收款 | 财务+老板 |
| 跟单员 | 人员 | | 全员 |
| 备注 | 长文本 | | 全员 |

**行级规则**：
- 状态用数据验证下拉
- 欠款用公式自动算
- 超期订单自动标红（条件格式）
- 表格冻结首行首列

### Sheet 3: 🧪 打样进度
- 字段：打样单号 / 关联订单 / 客户 / 款式 / 颜色 / 尺码 / 数量 / 打样状态 / 工厂 / 寄出日期 / 客户确认日期 / 备注
- 状态枚举：待打版 / 打版中 / 已寄出 / 客户确认 / 客户打回 / 已确认
- 关联字段必须能从订单表跳转（用超链接或 XLOOKUP）

### Sheet 4: 🏭 物料追踪（可选）
- 字段：物料编码 / 名称 / 规格 / 当前库存 / 安全库存 / 采购在途 / 预计到货 / 关联订单
- 库存低于安全库存时高亮警示

### Sheet 5: 👥 客户档案
- 字段：客户名 / 联系人 / 联系方式 / 区域 / 主营品类 / 历史订单数 / 累计金额 / 信用评级 / 备注
- 关联订单表，按客户筛选

### Sheet 6: 💰 财务对账（可选）
- 字段：订单号 / 应收金额 / 已收 / 未收 / 收款日期 / 发票号 / 备注
- 欠款汇总用 SUMIFS 自动算

### Sheet 7: 📈 月度报表（可选）
- 透视表：按月/按客户/按品类汇总
- 包含同比环比

## 大表字段分组（字段数 > 20 时必用）

当一张主表字段很多（如金融订单表 50+ 字段），**不要平铺**，必须按业务含义分组，方便录入和阅读。在字段定义里加"字段分组"列：

| 字段分组 | 字段名称 | 字段类型 | 必填 | 维护角色 |
|---|---|---|---|---|
| 状态流转 | 中台审批 / 放款状态 / 归档情况 | 单选 | 是 | 中台/后台 |
| 客户证件 | 身份证正反面 / 姓名 / 身份证号 / 住址 | 附件/文本 | 是 | 销售/OCR |
| 贷款信息 | 贷款产品 / 申请银行 / 总贷款额 / 期数 | 关联/金额 | 是 | 销售 |
| 资金字段 | 员工提成 / 供应商提成 / 银行应收 | 金额 | 否 | 财务 |
| 系统信息 | 创建时间 / 创建年月 | 日期/公式 | 是 | 系统 |

**分组原则**：
- 同一录入角色、同一业务环节的字段归一组
- 资金/敏感字段单独成组，便于统一配权限
- 系统自动字段（创建时间、年月公式）单独成组

## 录入交互约束（智能表格落地时必须标注）

demo 阶段就要把这些交互预期写清楚，避免实施时返工：

| 交互类型 | 说明 | 例子 |
|---|---|---|
| **OCR 自动识别** | 上传证件附件后自动带出文本字段 | 身份证正反面 → 姓名/民族/身份证号/住址/有效期 |
| **关联搜索选择** | 候选项很多（几百家）时禁止全量铺开，必须搜索选择 | 经销商库/渠道商库/产品库选择 |
| **1 对 1 自动带出** | 选定 A 后自动带出与之绑定的 B | 选贷款产品 → 自动带出申请银行 |
| **人员自动带出** | 选某人后带出其固定关联人 | 选业务员 → 自动带出业务主管、后台文员 |
| **创建年月公式** | 用公式字段从创建时间提取"yyyy年mm月"供月度看板 | `=TEXT(创建时间,"yyyy年mm月")` |

## 资金三态闭环表设计（对多方结算场景必用）

涉及"对银行/经销商/员工等多方的应收应付"时，用**基础库 + 流水表 + 回写汇总**三层：

- **基础库表**（如经销商库）字段必须含：`应付/应收`（rollup 自业务主表）、`已付/已收`（rollup 自流水表）、`待付/待收`（公式 = 应付 − 已付）
- **流水明细表**（如经销商付款）字段：`对象选择`（关联基础库）、`付款金额`、`登记人`、`登记时间`、`登记年月`
- 每新增一条流水，回写基础库的"已付总额"和"待付金额"

通用公式：
```
待付金额 = 应付总额 − 已付总额
应付总额 ← SUMIF(业务主表, 对象, 应付字段)
已付总额 ← SUMIF(流水表, 对象, 付款金额)
```

## 折旧公式字段链（固定资产/设备类资产管理必用）

资产类场景的净值需**按月自动折旧**，由一串公式字段联动算出。务必按下面的依赖顺序设计字段：

| 字段 | 类型 | 公式/来源 |
|---|---|---|
| 物资分类 | 单选/关联 | 选择，关联"折旧规则表" |
| 年限 | 数字/公式 | 从折旧规则表按物资分类**自动带出** |
| 可用月 | 公式 | `年限 × 12` |
| 入司时间 | 日期 | 录入（折旧起点） |
| 入司年月 / 当前年月 | 公式 | 取年月，用于算月数 |
| 使用月数 | 公式 | `当前年月 − 入司年月` |
| 月折旧率 | 公式 | `1 / 可用月`（或 `单价 / 可用月`，按客户口径） |
| 目前净值 | 公式 | `单价 − 单价 × MIN(使用月数/可用月, 1)`，**结果不低于 0** |

要点：
- 折旧粒度跟客户确认（本范式默认**按月**）；残值率/加速折旧等没提就标 ⚠️ 待确认
- "年限"靠关联规则表带出，不在主表硬编码，便于统一调整

## 状态驱动流转 + 留痕不覆盖 + 报废下账闭环（资产/资源流转类必用）

当资产/物品/资源会被反复"领用/借调/调拨/退还"且需追溯历史时：

- **主表 + 流转流水表**：流转动作记到流水表，**每次新增一条，绝不覆盖历史**（"一直滚动"）
- 流水表回写主表："当前持有部门/人""最新流转时间""流转记录"（关联汇总）
- **状态枚举**放主表单选字段（如 公用/个人/闲置/损坏/报废）
- **视图分流**：在用视图（状态≠报废）｜报废汇总视图（状态=报废 且 是否处理=否）
- **下账闭环**：勾选"是否处理"后，记录从报废汇总视图消失 = 完成下账（实现"处置后不在账上体现"）

> 通用性：这套"状态字段 + 流转留痕 + 是否处理闭环"可迁移到任何"台账 + 流转 + 注销"场景（设备、车辆、证照、IT 资产、库存等）。


## 视觉规范

### 表头
- 背景：`#1E5AFF`
- 文字：白色
- 字号：12pt
- 加粗
- 居中

### 斑马纹
- 偶数行：`#F7F8FA`
- 奇数行：白色

### 条件格式
- **超期**：背景 `#FFE5E5`，文字 `#E53935`
- **已完成**：背景 `#E5F7EC`，文字 `#00C853`
- **待办**：背景 `#FFF4E5`，文字 `#FF6B35`
- **紧急**：左侧 4px 橙色边条

### 数字格式
- 金额：`¥ #,##0.00`
- 百分比：`0.0%`
- 日期：`yyyy-mm-dd`

### 冻结
- 冻结首行
- 关键表冻结首列
- 拆分窗格在大数据表开启

## 数据验证

- 状态字段：下拉枚举
- 日期字段：禁用未来日期 / 禁用过早日期
- 金额字段：> 0
- 关联字段：用数据验证引用其他表

## 公式策略

| 场景 | 公式 |
|---|---|
| 自动算欠款 | `=总金额 - 已收款` |
| 自动算账期 | `=TODAY() - 约定交期` |
| 状态汇总 | `=COUNTIF(状态列, "打样中")` |
| 客户金额合计 | `=SUMIF(客户列, 客户名, 金额列)` |
| 同比环比 | 用当月 vs 上月 / 去年同月 |

## 命名规范

- Sheet 名用 emoji + 中文（如 `📊 数据看板`）
- 列名用中文，避免缩写（"跟单员"而非"跟单"）
- 不要用拼音或英文
- 表格首行必须是字段名（不要从第 3 行才开始）

- [ ] 金额字段有数字格式

## 与 docx/HTML 的一致性

xlsx 中的**字段名、状态枚举、流程节点**必须与 docx/HTML **完全一致**。生成前必须从 docx 章节 5/6 里提取字段清单，作为 xlsx 的字段来源。
