# 服务商信息

> **首次使用前必填**。三件套中的所有服务商相关信息（公司名、Logo、联系方式、版权）都会从这里读取。
> 留空 = 使用 `[服务商名称待填]` 占位符（不会凭空编造）。

## 基本信息

- **服务商名称**：（例：XX 科技有限公司）
- **品牌 Logo 文字**：（例：XX 科技）
- **联系电话**：（例：138-XXXX-XXXX）
- **邮箱**：（例：contact@xx.com）
- **公司地址**：（例：上海浦东张江高科技园区）
- **官方网站**：（例：www.xx.com）

## 业务定位

- **承载平台**：企业微信生态（智能表格 / 智能机器人 / 自建应用 / 微盘 / 工作台）— **固定，不可改为钉钉/飞书**
- **行业专长**：（例：制造业、外贸、连锁餐饮、医疗、SaaS、政企……）
- **典型客户类型**：（例：腰部企业、上市公司、政府单位、行业头部……）
- **项目周期**：（例：4-8 周、1-3 月、3-6 月）
- **团队规模**：（例：5-10 人、10-30 人、30+ 人）

## 视觉资产

- **主色（HEX）**：（默认 `#1E5AFF` 企微蓝）
- **辅色（HEX）**：（默认 `#00C853` 绿 + `#FF6B35` 橙）
- **Logo 文件**：（路径，如 `assets/logo.png`）
- **域名/品牌缩写**：（例：xx-tech、XX）

## 合作模式

- **标准报价区间**：（例：10-30 万、30-80 万、面议）
- **是否提供 POC**：（是/否）
- **是否含运维**：（是/否，X 个月）
- **是否含数据迁移**：（是/否）
- **是否含培训**：（是/否，X 场）

## 联系窗口

- **项目负责人**：（姓名 + 联系方式）
- **方案顾问**：（姓名 + 邮箱）
- **技术对接**：（姓名 + 邮箱）
- **客服/支持**：（电话/邮箱）
