# 通用设计规范

适用于定制开发方案生成器的**所有**交付物（HTML / Word / Xlsx）。

## 配色体系

### 主色板
| 用途 | 色值 | 名称 | 使用场景 |
|---|---|---|---|
| 品牌主色 | `#1E5AFF` | 企微蓝 | 标题、强调按钮、主流程线 |
| 辅助蓝 | `#3D7BFF` | 浅蓝 | 次级标题、辅助线 |
| 成功 | `#00C853` | 业务绿 | 已完成、达成指标、正向数据 |
| 警示 | `#FF6B35` | 橙红 | 待办、风险、待确认 |
| 危险 | `#E53935` | 错误红 | 异常、超期、阻塞 |

### 中性色板
| 用途 | 色值 |
|---|---|
| 主文字 | `#1A1A1A` |
| 次文字 | `#5A5A5A` |
| 弱化文字 | `#8A8A8A` |
| 分隔线 | `#E5E7EB` |
| 卡片底 | `#F7F8FA` |
| 页面底 | `#FAFBFC` |

## 字体

| 场景 | 中文字体 | 英文字体 | 字号 |
|---|---|---|---|
| 封面大标题 | 思源黑体 Heavy / 苹方 Bold | Inter Bold | 36-48pt |
| 章节标题 | 思源黑体 Bold | Inter SemiBold | 24-32pt |
| 小节标题 | 思源黑体 Medium | Inter Medium | 18-20pt |
| 正文 | 思源黑体 Regular / 苹方 Regular | Inter Regular | 14-16pt |
| 注释/说明 | 苹方 Light | Inter Light | 12pt |
| 数据数字 | DIN / Roboto Mono | DIN / Roboto Mono | 跟随场景 |

## 排版

- 行高：正文 1.6-1.8，标题 1.2-1.4
- 段距：段落之间 16-24px
- 圆角：卡片 8-12px，按钮 6-8px
- 阴影：浅 `0 2px 8px rgba(0,0,0,0.04)`，深 `0 4px 16px rgba(0,0,0,0.08)`
- 间距网格：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

## 图标

- 统一使用 **线性图标**（stroke 1.5-2px），颜色跟随文字
- 推荐库：Lucide / Tabler Icons / Feather
- 尺寸：内联 16px、卡片 24px、Hero 区 48-64px

## 数据可视化

- 柱状图/折线图：主色 `#1E5AFF`，对比色 `#00C853` / `#FF6B35`
- 数字大屏：必须有**目标值 vs 实际值**双指标
- 进度条：完成段 `#1E5AFF`，未完成 `#E5E7EB`
- 时间线：节点圆形 12px，连线 2px

## 品牌资产位

每份交付物必须有：
- 顶部 Logo 位（左上角，文字 + 标识）
- 底部版权位（"方案生成器（上海）数字科技有限公司 © 2025"）
- 右上角客户名 + 版本号

## 禁用项

- ❌ 渐变背景（除 Hero 区外）
- ❌ 阴影过重（不要 `box-shadow: 0 10px 30px rgba(0,0,0,0.5)` 这种）
- ❌ 超过 3 种主色同时出现
- ❌ 微软雅黑（已过时）
- ❌ 中英文之间无空格
- ❌ 标点符号用全角/半角混杂
