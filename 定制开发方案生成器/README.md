# 定制开发方案生成器

> **完全去角色化**的企业应用定制开发方案生成 Skill。丢入任意客户的需求材料，自动产出"可视化方案 HTML + 正式方案 docx + 智能表格 demo xlsx + 搭建 Prompt md"四件套。
> **不绑定特定服务商**（不是闪鱼、不是泽哥、不是任何公司专属）
> **不绑定特定客户**（不是城邦美商、不是亿选装饰专属）
> **不绑定特定行业**（服装外贸、家装、餐饮、制造、医疗……都行）

## 这个 Skill 给谁用

任何**企业微信定制开发服务商**——企业微信智能表格/智能机器人/自建应用的实施服务商、系统集成商、企业数字化顾问。接客户需求时按本 Skill 7 步流程，10 分钟内出四件套。**所有交付物只基于企业微信生态承载，绝不出现钉钉/飞书等友商平台。**

## 怎么用

### 方式 0：Claude 对话里直接调（最简单）

在 Claude 对话里直接说：

> "请用定制开发方案生成器，把这份客户材料生成四件套：[附材料]"

Claude 会自动按 SKILL.md 的 7 步流程生成。

### 方式 1：新客户初始化（推荐用于批量交付）

```bash
cd 定制开发方案生成器
python3 scripts/init_new_client.py <客户名> <行业> <场景>
```

脚本会：

1. 在 `examples/<客户名>/` 创建客户目录
2. 在 `scripts/` 创建该客户专属的 3 个 generate_*.py 脚本
3. 自动填入客户名、行业、场景
4. 打印清晰的"下一步操作"清单

然后：

1. 按指引编辑 3 个脚本 CONFIG 块（痛点、流程、KPI、字段、Sheet）
2. 依次运行 3 个脚本
3. 产物在 `examples/<客户名>/`

### 方式 2：手动修改 CONFIG（最快出 demo）

```bash
# 编辑 scripts/generate_html.py 顶部的 CONFIG 块
# 编辑 scripts/generate_docx.py 顶部的 CONFIG 块
# 编辑 scripts/generate_xlsx.py 顶部的 CONFIG 块
# 运行
python3 scripts/generate_html.py
python3 scripts/generate_docx.py
python3 scripts/generate_xlsx.py
# 产物在 examples/<客户名>/
```

适用场景：客户要快速看视觉稿，HTML 改 CONFIG 就能跑。

## 四件套交付物

按场景类型产出 3-4 份文件：

| 序号 | 类型 | 文件名规范 | 受众 | 适用场景 |
|---|---|---|---|---|
| ① | 可视化方案 | `{客户名}_{行业}_{场景}_可视化方案_V{版本}.html` | 客户决策层 | 全部场景 |
| ② | 正式方案 docx | `{客户名}_需求确认与方案设计表_V{版本}.docx` | 客户业务/IT 部门 | 全部场景 |
| ③ | 智能表格 demo | `{客户名}_智能表格交付_V{版本}.xlsx` | 客户一线使用方 | 全部场景 |
| ④ | 搭建 Prompt | `{客户名}_智能表格搭建Prompt_V{版本}.md` | 客户/实施团队 | **数据分析 / 流程协同 / 客户销售 / 积分激励类** |

> **第 ④ 份是新增的**。当场景需要"在真实平台搭建"时，必须额外输出，告诉用户具体步骤、字段配置、权限设置。
> **范例**：亿选装饰（家装/数据分析）、福鸿客户（制造业/积分激励）、广州鹏宁担保（金融担保/助贷订单管理）、贵州宏立城（行政/固定资产折旧管理）均含完整 ④ 件套。
> **多表关联场景**（积分激励/库存闭环/资金结算）：docx 与第 ④ 份必须含"表间关联关系"和"一期/二期范围划分"两章。

## 平台铁律：只用企业微信生态

我们是**企业微信定制开发服务商**。所有交付物（HTML/docx/xlsx/搭建 Prompt）**必须且只能**基于企业微信生态承载需求：

- ✅ 企业微信**智能表格**、**智能机器人**、**自建应用 / 工作台**、**审批/汇报/日程**、**微盘**、**OCR/通讯录/消息推送**
- ❌ 绝对禁止出现：钉钉、钉钉宜搭、飞书、飞书多维表格 / Lark Base、Notion、Airtable、简道云、明道云等任何友商平台
- 若客户原话提到友商平台 → 在 docx「⚠️ 待确认」记录并给迁移建议，方案主体仍按企业微信落地

## 核心设计原则：去角色化（平台除外）

| 维度 | 是否预设 |
|---|---|
| 服务商是谁 | 不预设（任何企业微信服务商） |
| 客户是谁 | 不预设（任何公司） |
| 行业是什么 | 不预设（任意行业） |
| 场景是什么 | 不预设（任意场景） |
| 使用平台 | ⚠️ **预设且锁定 = 企业微信生态**（不接受钉钉/飞书） |

**AI 怎么知道这些信息？** —— 服务商/客户/行业/场景从输入材料里**抽取**，抽不到标"⚠️ 待确认"；**平台无需抽取，恒定为企业微信**。

## 场景类型判断

| 场景类型 | 典型特征 | 模板选择 | 第 ④ 份 |
|---|---|---|---|
| **数据分析** | 数据看板/报表/BI/可视化/驾驶舱 | KPI 大屏 + 多维分析 | ✅ |
| **流程协同** | 审批/工单/订单/打样/巡检 | 流程图 + 状态机 + 角色泳道 | ✅ |
| **客户/销售** | CRM/客户档案/商机/漏斗 | 客户主数据 + 销售流程 | ✅ |
| **人力/行政** | HR/招聘/考勤/报销/培训 | 人员主数据 + 流程 | ⬜ |
| **积分/激励** | 积分/改善提报/奖励/兑换/排行榜/库存闭环 | **多表关联汇总** + 积分账户 + 奖品库存 | ✅ |
| **通用兜底** | 上述都不像 | 通用业务模板 | ⬜ |

> **积分/激励** 是"人力/行政"下的特殊子类型，核心是**跨表关联**（lookup/rollup/公式字段自动汇总积分与库存），范例见 `examples/福鸿客户/`。
> **HTML 叙事有两种结构**：营销式（默认，卖点驱动）与咨询诊断式（顾问视角，先诊断后开方，福鸿客户用此结构）。详见 `rules/html生成规则.md`。

## 三件套一致性原则

- **字段对齐**：docx 功能清单 ↔ xlsx 字段
- **流程对齐**：HTML 流程图 ↔ docx 流程章节 ↔ xlsx 状态字段
- **数字对齐**：所有量化指标在 3 处必须一致
- **角色对齐**：所有参与角色称谓统一
- **版本对齐**：版本号必须同步
- **服务商对齐**：所有文档中的服务商名必须相同

## 缺什么标什么

材料里没提到的客户名、行业、量化数据，**禁止凭空编造**，必须标 "⚠️ 待确认"。

## 调优流程

1. **首单**：跑通城邦美商或亿选装饰范例，熟悉流程
2. **第二单**：用 `init_new_client.py` 初始化新客户
3. **review 四件套**：哪里不对、哪里要改，明确记下
4. **反馈迭代**：把"哪些字段必须保留""哪些措辞客户买账"沉淀到 rules/
5. **范例归档**：完成 1-2 个客户后，把全套产物放到 `examples/{新客户}/`

## 关键决策记录

| 决策 | 原因 |
|---|---|
| **品牌不绑定** | 需求是给任意服务商用，Skill 名为"定制开发方案生成器" |
| **行业不绑定** | 跨服装外贸、家装、餐饮、制造、金融担保、行政资产管理六个行业验证通用性 |
| **场景类型驱动模板选择** | 数据分析、流程协同、CRM、HR、积分激励、资产台账各有侧重 |
| **跨表关联设计** | 积分激励/库存闭环/资金结算类需多表 lookup/rollup 自动汇总（福鸿、广州鹏宁担保验证） |
| **三层表结构 + 资金三态闭环** | 对多方结算场景：基础库 + 流水表 + 回写汇总，待付=应付−已付（广州鹏宁担保验证） |
| **折旧公式链 + 流转留痕 + 报废下账闭环** | 资产台账类：按月折旧公式串、流转记录不覆盖、报废勾选下账（贵州宏立城验证） |
| **知识库错配防御** | A 知识库可能与真实场景无关，一律以 B 沟通记录判定场景（贵州宏立城：挂金融知识库实做固定资产） |
| **HTML 两种叙事结构** | 营销式（卖点驱动）+ 咨询诊断式（先诊断后开方），按场景与材料语气选 |
| **配色用企微蓝 `#1E5AFF`** | 跨平台通用，客户认知强（可改 `rules/设计规范.md`） |
| **HTML 单文件 + 内联 CSS** | 方便邮件发送、离线打开 |
| **xlsx 7 个 Sheet** | 覆盖业务全流程（按场景调整） |
| **docx 10 章固定结构** | 客户已熟悉，沟通成本低 |
| **字体用苹方/思源黑体** | 中文显示最佳，跨平台一致 |
| **状态枚举三处统一** | 避免客户认知混乱 |
| **init_new_client.py** | 批量交付变"改 3 个脚本"的小工作量 |
| **第 ④ 份 Prompt** | 教客户/实施团队真实搭建，闭环 |
