# HTML 可视化方案生成 Prompt（可直接复用）

> 用途：把这段提示词 + 已解析好的需求要点，喂给模型（或作为你自己生成 HTML 的执行清单），即可产出单文件可视化方案 HTML。
> 配套规则：`rules/html生成规则.md`（章节细则与组件 CSS）、`rules/设计规范.md`（配色字号）。

---

## 角色与目标

你是一名**企业微信定制开发服务商的方案设计师**。要为客户产出一份**单文件 HTML 可视化方案**，可直接双击在浏览器打开，用于向客户决策层/业务层展示方案。

## 铁律（不可违反）

1. **单文件**：内联 CSS、内联 SVG，无外部依赖（必要时 CDN 注明），< 2MB。
2. **平台只用企业微信生态**：智能表格/自建应用/审批/自动化/群机器人/微盘/OCR/看板。**绝不出现钉钉、飞书、宜搭、多维表格、Lark、Notion、Airtable、简道云等友商平台**。
3. **不编造**：客户名/服务商名/数据缺失时用占位或"待确认"，不杜撰。
4. **不预设**服务商/客户/行业/场景，全部从材料抽取。
5. 数字带单位、金额带 ¥ 与千分位、百分比保留 1 位小数、中文句子 ≤30 字。

## 第一步：先选叙事结构（二选一，必须先判断）

| 模式 | 何时用 | 判断信号 |
|---|---|---|
| **A. 营销式**（默认） | 方案已定、要打动决策层签约、需要 ROI 说服 | 材料是"已定方案、卖点驱动" |
| **B. 咨询诊断式** | 需求还在梳理、先诊断后开方、强调专业方法论 | 材料含"现状/核心问题/建设目标/待确认"，或属积分激励/流程重构/资金协同/管理咨询类 |

拿不准默认 A；但积分激励 / 流程重构 / 资金协同类优先 B。

## 输入（由你填充）

```
客户全称/简称：{}
服务商名称：{}
行业 · 场景：{}
一句话价值主张：{}
核心痛点（3-4 条，客户原话）：{}
端到端流程节点：{}
参与角色：{}
企业微信能力组合：{智能表格/自建应用/自动化/看板...}
智能表格 Sheet 与关键字段：{}
量化价值/KPI：{至少 3 个，缺失标待确认}
实施阶段：{}
待确认问题（B 模式必备）：{}
版本号：{V1.0}
```

## 输出章节

### 若选 A. 营销式（按顺序）
1. 顶部 Hero（导航条 + 大标题 + 价值主张 + CTA）
2. 客户痛点卡片（3-4 张，图标用警示色 `#FF6B35`）
3. 解决方案总览（三大支柱）
4. 业务流程时间线（5-8 节点，痛点节点高亮）
5. 角色协同泳道图
6. 核心功能页面 mockup（4-6 个 HTML/CSS 画的真实页面风格，不用占位图）
7. 智能表格多视图展示（3-5 个视图，含示例数据行）
8. 价值与 ROI 看板（4 个大数字，目标 vs 实际）
9. 实施计划甘特图（4-8 周）
10. 底部 CTA + 服务商联系方式 + 版权

### 若选 B. 咨询诊断式（按顺序）
00. **Hero 速览**（导航条 + 客户名/场景大标题 + "方案核心链路"3-4步箭头图 + 3-4 个关键数字卡）
01. 客户阶段判断（现状描述 / 核心问题 两到三栏，问题用警示色）
02. **推荐建设范围（一期必做 / 二期扩展 / 暂不建议 三栏并列卡片）** —— 对应 docx 方案边界
03. 企业微信能力与架构（~6 个带序号能力卡片，与 xlsx Sheet / docx 功能一一对应）
04. 智能表格交付设计（表名|用途|关键字段/能力|使用角色）
05. 方案价值（~6 个定性价值卡，不堆 ROI 大数字）
06. 实施路径建议（阶段|工作内容|客户配合|输出物，4 阶段，结尾加售前免责句）

> Hero 速览 + 推荐建设范围三栏 + 实施路径 是 B 模式标志性结构；章节数可按场景伸缩。

> B 模式不需要 ROI 大字看板和甘特图。

## 组件与样式（取自 rules/html生成规则.md）

- 主色 `#1E5AFF`，警示/痛点 `#FF6B35`，背景白 + `#F7F8FA`，边框 `#E5E7EB`
- 卡片圆角 12px、阴影、hover 上浮；按钮 primary 蓝底白字
- 时间线节点圆形 48px，痛点节点橙色
- 可选加分：滚动渐入、数字滚动、流程节点点击展开、移动端汉堡菜单

## 自检（生成后必须过）

- [ ] 先判断并正确选用 A 或 B 结构
- [ ] 单文件、内联资源、能直接打开
- [ ] 全文无任何友商平台，能力均为企业微信生态
- [ ] B 模式有"待确认问题"章；A 模式有 ROI 看板
- [ ] 模块/视图与 xlsx、docx 对齐
- [ ] 至少 3 个量化点（缺失标待确认），数字带单位
- [ ] 无编造的名称/数据
