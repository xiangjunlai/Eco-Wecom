# 亿选装饰 · 智能表格搭建 Prompt

> 用途：把 `亿选装饰_智能表格交付_V1.xlsx` 中的 7 个 Sheet 在**企业微信智能表格**真实平台上逐个搭起来。
> 使用方式：将本文档整段粘贴给实施工程师，或按"搭建步骤"逐条执行。
> 预计搭建时长：2 个工作日（不含联调测试）。

---

## 一、概述

**业务场景**：家装前端数据分析（线索→签约→施工→复购的端到端数据驾驶舱）

**平台**：企业微信工作台 → 智能表格（建议放在「亿选装饰」企业下的"业务应用"分类）

**最终形态**：

- 1 个工作区（workspace）
- 7 个 Sheet：数据看板 / 数据源管理 / 维度配置 / 工地管理 / 客户档案 / 异常预警 / 趋势分析
- 权限组 5 个：老板 / 管理层 / 客户经理 / 设计师 / 项目经理
- 自动化规则 4 条：每日同步、异常预警、周报生成、月度归档
- 与 10 个数据源对接（4 自动 + 6 手工/半自动）

## 五、自动化规则（4 条）

### 规则 1：每日数据同步（6:00）

- **触发**：每天 06:00
- **动作**：
  - 从 10 个数据源拉取昨日数据
  - 更新 Sheet 2（数据源）状态
  - 刷新 Sheet 1（看板）KPI 数值
- **失败通知**：管理员 + 运营（推送企微消息）

### 规则 2：异常预警（每小时）

- **触发**：每小时整点
- **动作**：
  - 扫描 Sheet 4（工地管理）
  - 当"已超期 > 3 天"或"阶段停滞 > 5 天"时
  - 自动写入 Sheet 6（异常预警）
  - 推送企微消息给工长 + 工程部
- **去重**：同一工地同一异常 24h 内不重复推送

### 规则 3：周报生成（每周一 9:00）

- **触发**：每周一 09:00
- **动作**：
  - 汇总上周 7 天数据：新增线索 / 签约 / 完工 / 异常 / 营收
  - 写入"周报表"Sheet（可手工建）
  - 推送企微群消息（数据驾驶舱群 + 老板）
- **格式**：Markdown，包含 5 个核心数字 + 3 个 Top 异常

### 规则 4：月度归档（每月 1 日 1:00）

- **触发**：每月 1 日 01:00
- **动作**：
  - 复制上月数据到归档 Sheet
  - 趋势分析 Sheet 追加一行
  - 通知财务做对账
- **保留期**：12 个月，超期数据导出 Excel 备份

## 八、FAQ

**Q1：数据源接入失败怎么办？**
A：先确认 API 凭据 + 网络，参考"数据源管理"Sheet 的状态字段。如果持续失败超过 24h，切换为手工录入，并标注"⚠ 滞后"。

**Q2：工地超期判定标准是？**
A：当前规则为"进度 < 50% 且阶段在施工中 = 延期"。可在 Sheet 4 调整状态枚举值。

**Q3：客户等级怎么算？**
A：当前为手工维护。建议接入合同系统后改为自动：累计金额 ≥ 50万 = A，20-50万 = B，10-20万 = C，< 10万 = D。

**Q4：异常预警如何避免打扰？**
A：已配置 24h 去重。如需调整，可在"自动化规则 2"修改 cron 表达式。

**Q5：数据保留多久？**
A：在线 12 个月，超期导出备份。重要客户建议永久保留 Sheet 5。
