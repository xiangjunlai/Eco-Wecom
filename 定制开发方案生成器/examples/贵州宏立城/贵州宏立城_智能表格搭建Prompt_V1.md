# 企业微信智能表格搭建 Prompt

## 1. 搭建目标

请基于企业微信智能表格，为【贵州宏立城集团有限公司】搭建一套【固定资产盘点与折旧管理】系统。

本次搭建目标是：
- 将客户现有固定资产一级库/二级库和 Excel 表头搬到线上，形成统一固定资产库。
- 支持资产领用、借调、调拨等流转动作，保留历史记录，不覆盖。
- 按物资分类自动带出折旧年限，并按月计算当前净值。
- 报废资产进入独立报废汇总视图，通过“是否处理”完成下账闭环。
- 按部门、资产状态、净值等维度生成行政/财务/管理层看板。

整体定位：企业微信入口 + 智能表格数据底座 + 公式自动计算 + 流转回写 + 权限控制 + 数据看板。

## 2. 一期搭建范围

### 2.1 表格清单

| 表名 | 表类型 | 用途 | 使用角色 | 是否一期必做 |
|---|---|---|---|---|
| 固定资产库 | 核心主表 | 登记固定资产信息、分类、折旧、状态、当前所在部门、流转记录 | 全员查看受限；行政/财务维护 | 是 |
| 领用管理 | 流转表 | 记录领用、借调、调拨动作，回写固定资产库 | 全员提交；行政查看 | 是 |
| 资产折旧库 | 规则表 | 维护物资分类与折旧年限 | 财务/行政 | 是 |
| 部门库 | 组织辅助表 | 人员与部门映射，优先对齐企业微信组织架构 | 行政/财务 | 是 |
| 数据看板 | 仪表盘 | 资产数量、状态、净值、部门分布、报废处理 | 行政/财务/管理层 | 是 |

### 2.2 不在一期范围内

- 用车、用章、会议室预定等行政审批流程。
- 与财务系统/ERP 的折旧凭证、会计科目自动对接。
- 复杂二维码盘点、PDA 扫码盘点、跨系统实时双向同步。
- 替代完整固定资产财务系统。

## 5. 自动化规则

| 规则名称 | 触发条件 | 执行动作 | 通知对象 | 优先级 |
|---|---|---|---|---|
| 领用提交后回写资产部门 | 领用管理新增/修改记录 | 将资产库“目前所在部门”“最新领用时间”“领用记录”更新为本次记录 | 资产管理员 | P0 |
| 资产分类变更后更新折旧参数 | 固定资产库物资分类变更 | 从资产折旧库带出年限，重算可用月、使用月数、月折旧率、目前净值 | 财务/行政 | P0 |
| 资产状态变更提醒 | 资产状态变为损坏/闲置/报废 | 通知行政与财务跟进处置 | 行政、财务 | P1 |
| 报废待处理提醒 | 资产状态=报废且是否处理=否超过N天 | 提醒行政完成处置并通知财务下账 | 行政、财务 | P1 |

## 8. 命名规范

- 表名沿用客户交付结构：固定资产库、领用管理、资产折旧库、部门库、数据看板。
- 固定资产库字段优先对齐客户现有 Excel 表头；客户已确认可按当前表单字段设置。
- 资产状态统一使用：公用 / 个人 / 闲置 / 损坏 / 报废。
- 流转类型统一使用：领用 / 借调 / 调拨。
- 报废资产不要在“在用资产视图”显示；应进入“报废汇总视图”。

## 9. 搭建注意事项

- 不要把客户未确认的行政审批流程放进一期。
- 不要使用“金融服务/助贷”行业知识生成本项目表结构；本项目是行政固定资产管理。
- 领用/借调/调拨记录必须追加留痕，不得覆盖历史记录。
- 折旧按客户提供的物资分类与年限配置；若存在残值率、特殊折旧规则，先设为待确认。
- 涉及单价、净值、折旧等敏感字段，建议仅行政、财务和管理层可见。
