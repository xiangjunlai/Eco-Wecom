# 企业微信智能表格搭建 Prompt

## 1. 搭建目标

请基于企业微信智能表格，为【福鸿客户】搭建一套【制造业员工改善提报与积分激励】管理表格。

本次搭建目标是：

- 让员工可以在企业微信内极简提交改善建议。
- 改善提报后自动记录提报人积分；落实后自动记录落实人积分。
- 建立人员积分表，自动汇总建议积分、落实积分、已用积分和剩余积分。
- 建立奖品库存、采购入库、奖品领取闭环，实现库存自动联动。
- 建立部门排名和积分排行榜，方便管理层查看改善氛围和员工参与情况。

整体方案定位为：

企业微信入口 + 智能表格数据底座 + 改善提报 + 自动积分 + 奖品库存联动 + 数据看板。

请优先完成一期范围，不要扩展成完整 HR 系统、OA 审批系统或绩效系统。

## 2. 一期搭建范围

### 2.1 表格清单

| 表名 | 表类型 | 用途 | 使用角色 | 是否一期必做 |
|---|---|---|---|---|
| 改善提报 | 业务主表 | 登记员工改善建议及落实情况，生成提报/落实积分 | 全员、管理员 | 是 |
| 部门排名表 | 统计表 | 按部门统计建议条数并自动排名 | 管理人员、人事 | 是 |
| 人员积分表 | 汇总表 | 统计人员积分结余、建议积分、落实积分、已用积分、剩余积分 | 全员、管理员 | 是 |
| 奖品库存 | 库存表 | 登记奖品信息、积分档位、初始数量、入库数量、领取数量和现库存 | 全员、管理员 | 是 |
| 采购入库 | 业务明细表 | 登记奖品采购入库，自动增加库存 | 采购、管理员 | 是 |
| 奖品领取 | 业务明细表 | 登记奖品兑换领取，自动扣减积分和库存 | 全员、管理员 | 是 |

### 2.2 不在一期范围内的内容

以下内容不要在一期强行搭建，仅作为二期预留：

- 奖品领取审批流：员工申请 → 管理员审批。
- 按安全库存阈值自动提醒采购补货。
- 按改善金额或改善类型进行阶梯积分。
- AI 问数，例如“某员工当月积分”“某奖品库存”等。
- 通讯录自动同步人员表；一期先由人事核对维护真实姓名。

## 8. 命名规范

- 表名沿用 xlsx 中已有名称：改善建议 / 部门排名表 / 人员积分表 / 奖品库存 / 采购入库 / 奖品领取。
- 如需面向用户展示，可将“改善建议”重命名为“改善提报”。
- 字段命名保持中文，必要时备注英文名。
- 奖品按“名称 + 单位 + 积分档位”区分，同名不同积分档位分行。
- 自动化规则名称应体现触发条件和动作，例如“提报提交-提报人加分”。

---

## 9. 搭建注意事项

- 改善金额与改善节省时间是二选一必填，至少填一项，不能同时强制两个字段必填。
- 部门由提报人手动选择，不要强行绑定通讯录部门，避免组织变化导致数据错误。
- 人员姓名必须与企业微信通讯录真实姓名一致；搭建前由人事核对人员表。
- 提报人和落实人可为同一人。
- 奖品同名但积分档位不同必须分行录入。
- 积分和库存字段尽量用公式/关联汇总，避免人工维护。
- 管理员勾选“确认领取”后再扣减积分和库存，避免误扣。
- 不要把本项目扩展成完整 HR 系统或复杂审批系统。

## 10. 二期预留能力

后续可扩展：

- 奖品领取审批流。
- 库存低于安全阈值自动提醒采购补货。
- 按改善金额/改善类型自动计算阶梯积分。
- AI 问数：查询员工积分、部门排名、库存预警奖品。
- 改善案例沉淀与月度复盘报告。
