# Provider Assist Skill

## 简介

Provider Assist 是一款面向企业微信定制开发服务商的售前工具，帮助服务商快速完成客户调研、沟通整理和方案生成。

## 触发方式

用户发送以下任意内容启动 Skill：

- `售前`
- `/xiaoqiu`
- `开始售前`

## 流程概览

```
/clean                          ← 开始新客户前必用，清理上下文
    ↓
Step 1: 售前准备              ← 收集客户基础信息
    ↓
Step 2: 沟通纪要              ← 可多次上传，说"ok"确认
    ↓
Step 3: 需求整理              ← 微调后生成三种报告
    ├─ 技能A: 售前报告（HTML）
    ├─ 技能B: 技术报告（HTML）
    └─ 技能C: 报价方案（HTML）
    ↓
Step 4: 知识库进化            ← 可选
```

## 核心命令

| 命令 | 功能 |
|------|------|
| `/clean` | 清理当前客户会话的所有上下文，开始新客户 |
| `/memory` | 查看当前客户已收集到的所有信息 |
| `/help` | 显示帮助信息 |

## 数据存储

所有数据最终存储在平台服务器（`sining.cloud`），包括：

- 客户基本信息
- 沟通记录（多次上传）
- 生成的报告（HTML 链接）
- Token 消耗记录

## 生成前的 Token 预警

在生成报告前，系统会精确计算本次生成的 Token 消耗和预估费用，提示用户确认后再生成。

## 技术架构

- **后端 API**: `https://sining.cloud/api/skill/`
- **报告托管**: `https://sining.cloud/reports/`
- **认证方式**: API Key（受邀码）
