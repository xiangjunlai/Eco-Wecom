# /clean 命令

## 功能

清理当前会话的所有上下文，开始新的客户售前流程。

## 触发

用户发送 `/clean` 或说"开始新客户"、"清理会话"。

## 执行流程

### 1. 检查是否有未完成的流程

如果当前有进行中的客户数据（客户名称已收集但未生成报告），询问确认：

```
⚠️ 检测到未完成的客户流程：
- 客户：{client_name}
- 当前阶段：{current_step}

确认要清理吗？所有未保存的数据将丢失。
回复"确认清理"继续，或"取消"保留当前数据。
```

### 2. 执行清理

用户确认后，清理以下上下文：

```
当前客户档案 → 删除
沟通记录 → 删除
生成的报告 → 删除
Token 消耗记录 → 保留（用于统计）
```

### 3. 反馈

```
✅ 会话已清理！

可以开始新的客户流程。说"售前"或"/xiaoqiu"开始。
```

## 使用场景

- 用户完成一个客户的售前流程后
- 用户想要更换客户时
- 会话混乱、需要重新开始时

## 注意事项

- **清理前请确认**客户数据已保存或不再需要
- Token 消耗记录会被保留，用于平台统计
- 知识库不受影响
