01 / Background

客户阶段判断

客户已有本地 Excel 项目管理基础，但项目、任务、人力、财务与团队信息分散，当前重点不是建设重型系统，而是用企业微信入口 + 智能表格数据底座把项目交付链路先标准化。

行业设计 / 景观建筑 / 跨国多区域项目管理
当前工具本地 Excel + 聊天群 + 财务台账 + OA 待评估
核心角色管理层、PM、Team Leader、员工、财务、HR
建设阶段智能表格原型与一期落地评估
02 / Insight

从“表格升级”到“项目交付数据底座”

客户表层需求是项目进度、人力和财务看板，本质是跨区域设计交付缺少统一项目主表、标准阶段、人力口径和权限边界。

核心判断：一期先搭建 7 张智能表，跑通项目、人力、财务三条主链路。

OA/API 同步、机器人自动写入、AI 异常检测和工时预测建议作为二期验证，避免一期过度承诺。

1
项目主数据缺口Project Master 需要成为项目编号、阶段、状态、区域、负责人和财务进度的唯一主入口。
2
人力投入需要从百分比到小时小时制能更准确反映资源投入，也为后续成本分析和标准工时沉淀打基础。
3
财务与项目需要关联Payment Tracker 与 Project Master 关联后，管理层才能按项目查看开票、回款和逾期。
4
跨区域权限要前置按角色 + 区域配置权限，既保证高管全局可见，又避免财务敏感字段扩散。

05 / Tables

建议建设的 7 张智能表

一期建议先把表结构、关联、权限和基础提醒跑通，后续再评估接口与 AI。

表名类型用途使用对象一期
Project Master（项目主表）业务主表项目全生命周期管理：双编号、中英文项目名、状态、时间线、阶段、区域、负责人、财务进度、风险高亮。全员 / 管理层 / PM是
Task Schedule（任务调度表）明细记录表任务拆解与人力投入记录，按小时制统计成员负荷并触发超负荷提醒。员工 / Team Leader / PM是
Payment Tracker（财务追踪表）明细记录表记录开票、回款、多币种和预计/实际回款时间，按项目关联。财务 / PM / 商务是
Team Roster（团队名册）基础数据表维护姓名、职级、团队、办公室、角色、人力来源与是否团队领导。HR / PM / Team Leader是
Project Status Definition（阶段定义配置表）配置表标准化项目阶段名称、阶段类型和中英文说明，支撑状态字段。项目管理员 / PM是
Exchange Rate Reference（汇率参考表）配置表维护人民币、港币、美元等币种及汇率，供财务追踪换算。财务 / 项目管理员是/待确认
China Provinces（省份/地域辅助表）隐藏辅助表为 Province / 省份字段提供标准化下拉选项。系统引用是/可隐藏
06 / Permission

权限与看板设计

权限不是后置配置，而是跨国多办公室协同的前置设计。

全局可见

公司高管 / 职能部门

查看全公司项目数据和全局看板，按客户确认范围查看财务敏感字段。

区域隔离

区域办公室成员

仅查看所属办公室或自己参与的项目，避免跨区域数据混用。

敏感字段

财务人员

维护 Payment Tracker、汇率表和回款信息，可查看开票/回款敏感字段。

人力调度

Team Leader

维护任务分配、成员工时与任务状态，查看团队人力负荷。

个人视图

普通员工 / Designer

查看自己参与的项目和任务，填写自己的工时投入与任务状态。

项目推进

PM / 项目总监

维护项目状态、任务进度、负责人和阶段，关注项目推进与风险。

07 / Roadmap

实施路径建议

采用轻量试点方式，先跑通项目、人力、财务主链路，再扩展机器人和接口能力。

第 1 阶段

需求确认

确认双编号口径、阶段字典、区域/角色枚举、表字段、权限和看板指标。

第 2 阶段

原型设计

设计 Project Master、Task Schedule、Payment Tracker、Team Roster 等表结构和视图。

第 3 阶段

系统搭建

搭建 7 张表、关联关系、基础权限、自动化提醒和主要看板。

第 4 阶段

测试上线

组织 PM、Team Leader、财务、HR 进行试用，修正字段和权限。

第 5 阶段

试运行优化

按实际使用情况调整视图、提醒阈值、机器人能力和二期接口评估。

08 / Boundary

一期边界与二期建议

保持边界清楚，避免把接口、AI、复杂自动写入全部放进一期承诺。

一期

一期明确覆盖

7 张智能表、表间关联、基础权限、主要看板、阶段/任务/开票回款提醒。

二期

二期可扩展

OA/API 同步、机器人自动写入、AI 智能填报、异常检测、标准工时预测和高级成本分析。

不建议

暂不建议纳入

替代专业 OA/ERP/财务系统、复杂实时双向同步、薪资明细直接纳入智能表。
